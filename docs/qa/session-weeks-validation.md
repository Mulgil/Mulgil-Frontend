## 설계 결정

- 기존 `AcademicCalendar`의 봄 3월 2일, 가을 9월 1일 기준을 재사용한다.
- 과목의 `term` 값이 있으면 해당 학기를 우선 사용한다.
- 시간표 슬롯마다 16주간 실제 차시를 만들고, 전역 `sessionNumber`와 주차 내 `n차시`를 분리한다.
- 기존 수동 차시는 변경하지 않고, 차시가 없거나 자동 생성 도중 일부만 저장된 과목만 보완한다.
- 이번 PR에서는 실제 외부 스토리지 업로드와 AI 생성 성공을 판정하지 않는다.
